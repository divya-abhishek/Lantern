# Lantern 1.0.0

Lantern brings local video playback and Windows screen sharing to Android phones, TVs, and projectors. Start with the Windows ZIP and signed Android APK from the release.

- One Windows setup step installs the streaming tools and sets up access on a private home network.
- Connect from Windows and approve on the receiver. Screen sharing starts and stops from the PC.
- System sound is enabled by default. Choose 720p or 1080p at 30 or 60 FPS.
- Compatible videos play directly. AVI and other incompatible files can be prepared on the PC for normal playback and seeking.
- The Android home screen adapts to narrow phones. Playback supports touch and remote navigation with audio and subtitle controls.

The Windows package and signed APK were exercised on Windows and an Android emulator. The Windows host produced a 1080p60 stream with audio. Earlier Pixel 9 runs exercised 720p30, 720p60, and 1080p30 with audio. Smoothness at 1080p60 over Wi-Fi and playback on a physical projector still need verification. Start at 720p30 for lower-powered receivers.

First-time Windows setup requires Internet access to download FFmpeg. Casting and media playback use your local network. Use Lantern on a trusted home network.
